# Honest portfolio scope

Use this prototype to demonstrate the structure and implementation approach. Do not claim it is a production deployment or that it has already monitored a real 400,000-record customer database.

Suggested wording after you personally run and understand the demo:

> Developed a Python/PostgreSQL prototype for FMCSA daily-difference monitoring. It normalizes USDOT and MC identifiers, compares source records, stores a historical event ledger with unique event keys, produces daily run reports, and provides an n8n schedule trigger with optional Zoho CRM alert upsert. The project remains a development prototype; production data mapping, customer-specific CRM fields, load validation, and deployment hardening are documented next steps.

Only use that wording after you have actually run the prototype and reviewed its output. If you have not yet run it, call it an implementation starter rather than a completed project.
